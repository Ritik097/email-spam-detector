## 1. Common Errors and Fixes

---

### Error 1: `FileNotFoundError: 'model.pkl' not found`

**Cause:** You ran `python app.py` without first training the model.

**Fix:**
```bash
# Step 1: Generate the dataset (if you haven't already)
python dataset/generate_dataset.py

# Step 2: Train the model
python train_model.py

# Step 3: Now start the app
python app.py
```

---

### Error 2: `ModuleNotFoundError: No module named 'flask'`

**Cause:** The required Python libraries are not installed.

**Fix:**
```bash
# Activate your virtual environment first
source venv/bin/activate

# Then install all dependencies
pip install -r requirements.txt
```

---

### Error 3: `KeyError: 'message'` or `KeyError: 'label'` when loading dataset

**Cause:** The CSV file uses different column names than expected.

**How `train_model.py` handles this:**
The script automatically detects the SMS Spam Collection format (`v1`, `v2`)
and renames them to `label` and `message`. If you use a custom dataset, make
sure it has exactly these two column names.

**Fix for a custom dataset:**
```python
# In train_model.py, after reading the CSV, rename your columns:
df.rename(columns={"your_label_column": "label",
                   "your_text_column":  "message"}, inplace=True)
```

---

### Error 4: `ValueError` during `predict_proba`

**Cause:** The model was not trained with probability support, or `classes_` is
not available.

**How it's handled:** The pipeline uses `MultinomialNB` which always supports
`predict_proba`. If you switch to a different classifier, make sure it supports
probability estimation or remove the confidence score feature.

---

### Error 5: Poor Prediction Accuracy (below 80%)

**Cause:** The sample dataset generated by `generate_dataset.py` is small and
repetitive (300 rows total).

**Fix:** Use a larger, real-world dataset:
1. Download the [SMS Spam Collection dataset](https://archive.ics.uci.edu/ml/datasets/sms+spam+collection)
   (5,574 messages).
2. Place it at `dataset/emails.csv`.
3. Re-run `python train_model.py`.

Expected accuracy with the SMS Spam Collection dataset: **97–99%**.

---

### Error 6: `Address already in use: (127.0.0.1, 5000)`

**Cause:** Another process is already using port 5000, or a previous Flask
instance is still running.

**Fix:**
```bash
# Find and kill the process using port 5000
lsof -ti :5000 | xargs kill -9

# Then restart the app
python app.py
```
Or change the port in `app.py`:
```python
app.run(debug=True, host="127.0.0.1", port=5001)
```

---

### Error 7: Spam samples load but Predict returns an error

**Cause:** The Flask server may not be running, or the browser is making a
request to the wrong address.

**Fix:**
1. Check that the terminal shows "Running on http://127.0.0.1:5000".
2. Confirm the browser address bar shows `http://127.0.0.1:5000`.
3. Open the browser's developer console (F12) and check the Network tab for
   the failed request details.

### Improvement 2: Text Preprocessing Pipeline
Add a simple text cleaning step before CountVectorizer:
```python
import re

def clean_text(text):
    text = text.lower()
    text = re.sub(r"http\S+", " url ", text)      # replace URLs with 'url'
    text = re.sub(r"\d+", " num ", text)           # replace numbers with 'num'
    text = re.sub(r"[^\w\s]", " ", text)           # remove punctuation
    text = re.sub(r"\s+", " ", text).strip()       # collapse whitespace
    return text
```
Apply this to both training data and prediction input.

### Improvement 3: TF-IDF Instead of CountVectorizer
`TfidfVectorizer` weighs rare, significant words more heavily than common ones.
It often improves precision:
```python
from sklearn.feature_extraction.text import TfidfVectorizer

pipeline = Pipeline([
    ("vectorizer", TfidfVectorizer(stop_words="english")),
    ("classifier", MultinomialNB()),
])
```
